### 2.3 Economic Motivation for Feature Engineering Format Restrictions
We deliberately structure our trailing macroeconomic regressors into three distinct mathematical formats, aligning with behavioral economics principles regarding how households functionally evaluate the state of the economy:

**1. Raw Levels (e.g., Unchanged Rates)**
Raw levels establish the *baseline context* or anchor for the respondent. An individual's fear of unemployment realistically increasing is heavily mathematically dependent on the current baseline condition. For instance, expecting unemployment to rise when the current base level is 3.5% represents a significantly different psychological environment than expecting it to rise when the base is naturally anchored at 9.0%.

**2. Absolute Differences (1-month & 12-month)**
Absolute differences are the correct method to measure momentum for variables that are *already expressed as percentages or rates* (like FEDFUNDS interest rates or the Unemployment Rate). If the Fed Funds rate jumps from 1.0% to 2.0%, that is cleanly quantified as a +1.0% absolute point jump. If we incorrectly computed a relative percentage change for this momentum block, it would register as an extreme +100% surge, which artificially exaggerates the data and distorts linear regression sensitivity boundaries.

**3. Relative Percentage Changes (1-month & 12-month)**
Raw values for massive economic indices (like the S&P 500 index, real GDP level, or the abstract dollar indices) are non-stationary and functionally useless to the average consumer. A consumer doesn't shape their personal expectations systematically based on whether the S&P 500 is trading at exactly 4,000 points or 4,100 points; they base it on the contextual news headline that "the stock market is up 20% this year." By strictly computing 1-month and 12-month percentage shifts, we transform non-stationary index evaluations into stationary, normalized variables that replicate how households perceive and measure performance constraints.

**Model Architecture & Scaling Requirements:**
*   **Feature Scaling:** Natively required! Both Ridge and Lasso estimators apply absolute penalty constraints ($\mathcal{L}_1$ / $\mathcal{L}_2$ norms) to regression coefficients. If variables are on entirely different numerical scales (e.g., S&P 500 at 4500 vs. Unemployment Rate at 0.04), the penalty mechanism structurally collapses. Therefore, we rigidly nest `StandardScaler()` directly into our `Pipeline` to normalize all features internally utilizing only the training fold distribution.
*   **Hyperparameters:**
    *   `LinearRegression`: No hyperparameters required. It solves the ordinary least squares natively.
    *   `RidgeCV` & `LassoCV`: Both mathematically depend on the Penalty Strength Hyperparameter (`alpha`). We implement internal cross-validation mechanisms searching a massive multidimensional logarithmic grid of potential alpha candidates dynamically resolving the optimal configuration.

# Helper Function 1: Machine Learning Evaluation Architecture (No Graphical Overlay)

def calculate_continuous_regression(target, feature_set_name, features):
    df_eval = df_model[['date', target] + features].dropna().copy()
    
    mask = df_eval['date'] < '2024-01-01'
    X_train, y_train = df_eval[mask][features], df_eval[mask][target]
    X_test, y_test   = df_eval[~mask][features],  df_eval[~mask][target]
    
    models = {
        'LinearRegression': LinearRegression(),
        'RidgeCV': RidgeCV(alphas=np.logspace(-2, 4, 30), store_cv_results=True),
        'LassoCV': LassoCV(alphas=np.logspace(-4, 2, 30), cv=5, max_iter=20000, n_jobs=-1, selection='random')
    }
    
    outputs = []
    
    for model_name, estimator in models.items():
        pipe = Pipeline([('scaler', StandardScaler()), ('model', estimator)])
        pipe.fit(X_train, y_train)
        fitted = pipe.named_steps['model']
        
        best_alpha = None
        cv_validation_mse = None
        
        if model_name in ['RidgeCV', 'LassoCV']:
            best_alpha = fitted.alpha_
            # Extract optimal CV score dynamically
            if model_name == 'RidgeCV':
                if hasattr(fitted, 'cv_results_') and isinstance(fitted.cv_results_, dict):
                    cv_mse_path = fitted.cv_results_['mean_test_score']
                    cv_validation_mse = np.abs(np.max(cv_mse_path)) if np.mean(cv_mse_path) <= 0 else np.min(cv_mse_path)
                else:
                    res = fitted.cv_results_ if hasattr(fitted, 'cv_results_') else fitted.cv_values_
                    cv_validation_mse = np.min(np.mean(res, axis=0))
            elif model_name == 'LassoCV':
                cv_validation_mse = np.min(np.mean(fitted.mse_path_, axis=1))
        
        y_test_pred = pipe.predict(X_test)
        rmse_test = np.sqrt(mean_squared_error(y_test, y_test_pred))
        r2_test = r2_score(y_test, y_test_pred)
        
        # We append a massively comprehensive output object preserving the physical pipeline model seamlessly!
        outputs.append({
            'Target Variable': target,
            'Feature Depth': feature_set_name,
            'Regressive Algorithm': model_name,
            'Optimized Alpha': best_alpha,
            'Validation CV MSE': cv_validation_mse,
            'Test OOS RMSE': rmse_test,
            'Test OOS R2': r2_test,
            'model_pipeline': pipe,
            'df_eval_used': df_eval, # Passing isolated cleaned datasets
            'features_used': features
        })
        
    return outputs

# Helper Function 2: Validation Curve Renderer

def plot_validation_curve(model_output_entry):
    pipe = model_output_entry['model_pipeline']
    m_name = model_output_entry['Regressive Algorithm']
    target = model_output_entry['Target Variable']
    fitted = pipe.named_steps['model']
    
    if m_name == 'LinearRegression':
        print(f"LinearRegression possesses no hyperparameter iterations to natively trace/plot for {target}.")
        return
        
    if m_name == 'RidgeCV':
        if hasattr(fitted, 'cv_results_') and isinstance(fitted.cv_results_, dict):
            cv_mse = fitted.cv_results_['mean_test_score']
            if np.mean(cv_mse) <= 0: cv_mse = -cv_mse
        else:
            res = fitted.cv_results_ if hasattr(fitted, 'cv_results_') else fitted.cv_values_
            cv_mse = np.mean(res, axis=0)
            
        alphas = fitted.alphas
        color = 'royalblue'
        
    elif m_name == 'LassoCV':
        cv_mse = np.mean(fitted.mse_path_, axis=1)
        alphas = fitted.alphas_
        color = 'firebrick'

    fig, ax = plt.subplots(figsize=(6, 3))
    ax.plot(np.log10(alphas), cv_mse, marker='s', markersize=4, color=color)
    ax.set_title(f'{m_name} Cross-Validation Path ({target})', fontsize=10, fontweight='bold')
    ax.set_xlabel('log10(Alpha Penalty Strength)')
    ax.set_ylabel('Mean Squared Error (MSE)')
    ax.grid(True, alpha=0.3)
    return fig

# Helper Function 1: Core Classification Engine Definition

def calculate_binary_classification(target, feature_set_name, features):
    df_eval = df_model[['date', target] + features].dropna().copy()
    
    # Establish strict OOS boundaries globally
    mask = df_eval['date'] < '2024-01-01'
    X_train, y_train = df_eval[mask][features], df_eval[mask][target]
    X_test, y_test   = df_eval[~mask][features],  df_eval[~mask][target]
    
    outputs = []
    class_models = ['Logistic Regression', 'Random Forest']
    
    for m_name in class_models:
        if m_name == 'Logistic Regression':
            # Rigorously implementing cv=5 and n_jobs=-1 internally!
            pipe = Pipeline([('scaler', StandardScaler()), ('model', LogisticRegressionCV(Cs=10, cv=5, penalty='l2', solver='lbfgs', max_iter=2000, n_jobs=-1))])
            pipe.fit(X_train, y_train)
            fitted = pipe
            best_param = f"Opt. C: {pipe.named_steps['model'].C_[0]:.4f}"
            
        elif m_name == 'Random Forest':
            rf_pipe = Pipeline([('scaler', StandardScaler()), ('model', RandomForestClassifier(random_state=42))])
            # Aggressively restricting model grid dimensionality explicitly to save RAM memory structures 
            param_grid = {'model__n_estimators': [50, 100], 'model__max_depth': [5, 10]}
            search = GridSearchCV(rf_pipe, param_grid, cv=5, scoring='f1', n_jobs=-1)
            search.fit(X_train, y_train)
            fitted = search.best_estimator_
            best_param = str(search.best_params_)

        # Calculate Training sample variables recursively as requested
        y_train_hat = fitted.predict(X_train)
        y_test_hat = fitted.predict(X_test)
        
        outputs.append({
            'Target': target,
            'Features': feature_set_name,
            'Classifier': m_name,
            'Opt Parameters': best_param,
            'Train Acc': accuracy_score(y_train, y_train_hat),
            'Train Prec': precision_score(y_train, y_train_hat, zero_division=0),
            'Train Rec': recall_score(y_train, y_train_hat, zero_division=0),
            'Train F1': f1_score(y_train, y_train_hat, zero_division=0),
            'Test Acc': accuracy_score(y_test, y_test_hat),
            'Test Prec': precision_score(y_test, y_test_hat, zero_division=0),
            'Test Rec': recall_score(y_test, y_test_hat, zero_division=0),
            'Test F1': f1_score(y_test, y_test_hat, zero_division=0),
            'Test Acc': accuracy_score(y_test, y_test_hat),
            'Test Prec': precision_score(y_test, y_test_hat, zero_division=0),
            'Test Rec': recall_score(y_test, y_test_hat, zero_division=0),
            'model_pipeline': fitted,
            'df_eval_used': df_eval,
            'features_used': features
        })
    return outputs
